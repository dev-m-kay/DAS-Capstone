(async) adminFetch(endpoint, optionsopt) → {Promise.<Object>}

Admin-scoped wrapper around the shared `apiFetch` (defined in `app.js` and exposed on `window`). IMPORTANT: this is named `adminFetch` (not `apiFetch`) on purpose — both files load as classic scripts into the same global scope, and `app.js` already declares `apiFetch` at module top level. Redeclaring `apiFetch` here with `const` would be a global-scope `SyntaxError` and abort *every* statement in this file (including the `DOMContentLoaded` listener that wires the page up). The shared fetch is looked up at *call* time rather than at module-load time so script-evaluation order can never leave us with a stale `undefined` reference. Prefixes the endpoint with API, redirects to login when no token is present, returns `{ __error: true, message }` on non-2xx responses (so callers can surface the error inline), and returns the parsed JSON body on success.
